# ToolSeeds

Programming tools can be transmitted as prompts instead of finished software. ToolSeeds is a library of these prompts: instructions for creating or adapting useful programming tools with an AI coding assistant.

## What is a tool seed?

A tool seed describes a tool's purpose and expected behavior in enough detail for an AI coding assistant to build it in the context of your project. Unlike a finished application, a seed can be adapted to your language, framework, and constraints.

## Using a seed

Choose a seed that fits the task, then give its prompt to your coding assistant along with any relevant project context or constraints. Review the resulting code, run the project's tests, and adjust the implementation as needed.

## Contributing a seed

Write seeds as self-contained prompts. Describe the problem the tool solves, its expected behavior, important constraints, and how to verify the result. Include examples where they make the requirements clearer, and avoid assuming a particular project setup unless the seed is specifically intended for it.
